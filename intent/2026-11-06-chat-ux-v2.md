# Intent: Chat UX v2 (conversation screen, reactions, personalisation, stickers)

- **Author:** Hoan
- **Status:** draft
- **KAN key:** KAN-131 (bug), KAN-132, KAN-133, KAN-134, KAN-135 (stories)

## Problem

Feedback on the v1.3.0 mobile UI (Figma review, 2026-11-06):

- Trainee site: inside a conversation the bottom tabs still show and there is no Back button; the online dot is not next to the other person's name; the online / last active text is not directly under that name.
- Admin site: on iPhone the "Thêm user" sheet is clipped. Only the title, the name field and the "Email đăng nhập" label show; the email input sits behind the submit button and cannot be typed into, so no user can be created from a phone.
- Chat lacks what people expect from Messenger / TikTok DMs: time breaks, reactions, reply, edit, copy, unsend, nicknames, stickers, your own bubble colour.

## Proposed outcome

- A focused conversation screen: no tab bar, Back, name + green dot, status under the name, a time break after 30 minutes.
- The Add user sheet (and every bottom sheet) fully usable on iPhone, with and without the keyboard.
- Double-tap heart; long-press reactions plus Reply / Copy / Edit / Delete; edits keep history; unsend for everyone.
- Nicknames for each other and for yourself (no renaming, Hoan 2026-11-06), pick your own bubble colour that the other side sees.
- A sticker panel with a free, licensed sticker pack.

## Affected users and systems

Trainees and admins (PTs). `features/chat`, `components/common/BottomSheet`, `components/layout/UserTabBar`, `features/members` (Add user), `db/schema.ts` (additive tables and columns), the chat sync payload, Ably events, push text.

## Constraints

- Additive schema only (Vercel runs `drizzle-kit push` on production).
- Polling fallback must keep working without Ably.
- Vietnamese UI copy; code and docs in English.
- No TikTok assets (copyright): stickers come from an open-licence pack.

## Out of scope

Photos / attachments (KAN-106..108, Pending), group chats, message search, per-conversation themes that change both sides' colours.
